# Architecture

```
Асуулт (Монгол / Латин-Монгол / English)
        │
   Agent (LLM tool use, prompts/v2.md, level: brief|standard|student|researcher)
        │   provider давхарга (llm.py): Gemini (анхдагч) | Anthropic
        │  search_history(queries[], year_from?, year_to?)      report_gap(topic)
        ▼
   Searcher
     1. alias expansion      Тэмүжин ↔ Temüjin ↔ 铁木真 ... (data/aliases.json)
     2. vector search        bge-m3 (олон хэл, cross-lingual)
     3. BM25                 Кирилл/Латин үгээр, CJK тэмдэгтээр
     4. RRF fusion
     5. year filter          chunk-д дурдагдсан оноор
     6. reranker (optional)  bge-reranker-v2-m3, хэрэглэгчийн анхны асуултаар
     7. per-source cap       нэг эх сурвалж бусдыг дарахаас сэргийлнэ
        │
   Хариулт + [S#] ишлэл ──► (optional) verify: ишлэл бүрийг тусдаа дуудлагаар шалгаж, батлагдаагүйг засна
        │
   Үр дүн: answer, sources, invalid_citations, gap, searched
```

## Өөрийгөө сайжруулах мөчлөг

| Дохио | Хаана хадгалагдах | Юунд хэрэглэх |
|---|---|---|
| Агент "архивт алга" гэж report_gap дуудсан | `data/gaps.jsonl` | `mha gaps`: дараа нь аль эх сурвалжийг нэмэх жагсаалт |
| Хэрэглэгч 👎 дарсан | `data/feedback.jsonl`, `eval/candidates.jsonl` | Та зөв хариултыг нөхөж `eval/questions.jsonl`-д нэмнэ |
| Eval оноо | `eval/history.jsonl`, `eval/baseline.json` | Prompt/model/хайлтын өөрчлөлт бүрийг хэмжиж, буурвал `mha eval` exit 1 |
| Prompt хувилбар | `prompts/vN.md` | `MHA_PROMPT=v1 mha eval` ба `v2`-ийг харьцуулна |

Систем өөрөө мэдлэгээ **автоматаар өөрчлөхгүй**: алдаа, цоорхойг цуглуулж, хүн баталгаажуулж, eval-аар хэмжинэ.
Түүхийн хувьд буруу мэдээлэл өөрөө тархах эрсдэлээс сэргийлэхийн тулд зориуд ингэсэн.

## Хариуцлагатай байдлын дүрэм
- Хариулт бүр архиваас олдсон хэсэгт тулгуурлана, ишлэлгүй мэдэгдэл гаргахгүй.
- Эх сурвалж зөрвөл зэрэгцүүлж харуулна.
- Архивт байхгүй бол "мэдэхгүй" гэж хэлж, цоорхой бүртгэнэ.
- Лицензгүй эх сурвалжийг индекслэхгүй (`mha check-sources`).

## Мэдэгдэж буй хязгаарлалт
- Хайлтын чанар шууд эх сурвалжийн чанар, хэмжээнээс хамаарна. Цэвэр текст хэрэгтэй, скан PDF-ийн OCR алдаа хайлтад нөлөөлнө.
- Латин бичигтэй Монгол асуултыг Кирилл болгох ажлыг модел өөрөө хийдэг (тусгай хөрвүүлэгч алга).
- Eval нь түлхүүр үг + ишлэлийн бүтцийг шалгадаг, утга зүйн зөв байдлыг бүрэн хэмждэггүй. Үүнийг `--verify` болон хүний шалгалтаар нөхнө.
- Хуучин монгол бичиг (ᠮᠣᠩᠭᠣᠯ бичиг) шууд дэмжигдээгүй.
